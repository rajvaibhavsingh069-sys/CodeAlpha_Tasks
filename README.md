# 1. Flashcard Quiz App 📚

A simple Flashcard Quiz App built with Flutter and Dart to help users study efficiently using customizable flashcards.

## Features

* Create flashcards with questions and answers
* Reveal answers using a **Show Answer** button
* Navigate through cards with **Next** and **Previous** buttons
* Edit existing flashcards
* Delete unwanted flashcards
* Clean and user-friendly interface

## Tech Stack

* Flutter
* Dart

## Getting Started

```bash
git clone https://github.com/your-username/flashcard-quiz-app.git
cd flashcard-quiz-app
flutter pub get
flutter run
```

## Usage

1. Add a flashcard with a question and answer.
2. Review cards one by one.
3. Click **Show Answer** to reveal the answer.
4. Use **Next** and **Previous** to navigate.
5. Edit or delete flashcards as needed.
